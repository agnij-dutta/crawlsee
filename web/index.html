crawlsee

Your eyes see the page after CSS and JavaScript. Crawlers, link previews and AI answer engines read the HTML your server sends. This shows you that version.

Check a live URL (CLI)

Browsers can't fetch other sites (CORS), so live checks run in your terminal. crawlsee is not on npm yet, so npx crawlsee does not work today. Run it from a clone of github.com/agnij-dutta/crawlsee:

git clone https://github.com/agnij-dutta/crawlsee.git
cd crawlsee && npm ci && npm run build
node dist/cli.js https://your.site
node dist/cli.js https://your.site --query "freelance web3 engineer"
node dist/cli.js https://your.site --render     # diff raw HTML vs headless Chromium
node dist/cli.js https://your.site --json

Once it is published, the same commands will work as npx crawlsee https://your.site.

Or check by hand, the right way: curl -sL https://your.site | sed 's/<[^>]*>/ /g' | tr -s ' ' | grep -i "views". Use -L because apex domains often redirect, and strip tags because the number and its unit usually sit in separate elements.

Or paste HTML

Use view-source: (not DevTools Elements, which shows the page after JavaScript). Nothing leaves your browser.

Every check comes from a real bug: an H1 Google read as "Webuy,operate,andscale...", stats served as "0 M+ Views/Month", a hero at opacity 0 until hydration, a 3.3 MB icon chunk, and a portfolio that said "select engagements" while buyers asked ChatGPT for "available for freelance".

Scores are heuristics. Read the findings, not just the number.
